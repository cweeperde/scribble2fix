AI tools

Connecting sets up everything the tool needs: the scribble2fix MCP server, a /scribble command where the tool has commands, and permission to use it without asking each time. The AI can then read your captures and ask you for a scribble (it always asks in the chat first).

Using another AI tool? Connect it by hand
